# Convention record for this change

- Scope and candidate: paths allowed to change, content identifier, current writer.
- Basis adopted: format/lint/type configuration, language/framework version, similar implementations, applicable exceptions.
- Mode: read-only suggestions / authorised implementation; a review request is not write permission.

## Verification

Actual commands/manual checks, tool versions, target file scope, exit codes and key diagnostics; behaviour assertions and results for semantic changes.
Mark anything not run as unverified explicitly; do not infer a pass from empty output.

## Close-out

Give substantive issues and style suggestions separately; remaining gaps, generation-source/third-party boundaries, unresolved conflicts and next step.
Shared state is recorded by the project's existing maintainer; exceptions do not automatically change global rules.
