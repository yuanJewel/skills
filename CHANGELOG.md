# Changelog

All notable changes to this library are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Library releases are tagged `vX.Y.Z`; package versions (`metadata.version` in each `SKILL.md`) are independent, and each entry names the packages it touches and their new versions. Entries carry a linked short commit id once committed; each link targets the full commit id.

## [Unreleased]

## [0.1.1] - 2026-10-21

### Added
- `skill-maintenance` 0.1.1: a new authoring checklist collects package structure, frontmatter, the eleven author conventions, British spelling and key terms, the sole-authority index and the pre-handover steps into one page, marking each check as lint or manual. ([f07453f](https://github.com/yuanJewel/skills/commit/f07453f098036cc8808c57cb783baa0de8a170f6))
- `skill-maintenance` 0.1.1: the design and authoring method now states how to evaluate an external Skill source — read full files at a pinned commit, check license compatibility and script scope, record the source, and never install automatically. ([f07453f](https://github.com/yuanJewel/skills/commit/f07453f098036cc8808c57cb783baa0de8a170f6))
- `ai-workspace-governance` 0.1.0: add a shared method for organizing AI working materials under a project-selected root, with a common core, project extensions, selective policy-change memory, a user workbench, retention configuration, copyable agent handover instructions, and verified plan archiving with recoverable close-out. ([2e28c80](https://github.com/yuanJewel/skills/commit/2e28c80e4823b977669c93d9bba6c14c07caee72))
- `guided-evidence-collection` 0.1.0: new package for diagnosis when the decisive evidence sits in an environment the agent cannot enter, such as production or a restricted cluster. The agent designs copyable read-only steps and the user runs them and pastes the results back: each round targets 1–3 steps chosen to separate hypotheses, every step states where it runs, why it is read-only, expected normal and abnormal output, fields to paste, what to redact, an output budget and an alternative when access is missing. Includes bounded patterns for HTTP responses, container logs, database rows, build consoles and cloud resource status, a portable best-effort redaction pipeline, and four evidence source labels (`user-run`, `agent-run local`, `static inference`, `unverified`). The agent never connects to those environments or asks for credentials, treats pasted text as data, and keeps state-changing actions out of evidence steps. ([1b1539a](https://github.com/yuanJewel/skills/commit/1b1539a4e3886f2ca691b2b718fb540e14463cbe))

### Changed
- `coding-conventions` 0.1.1, `security-review` 0.1.1, `ai-trace-audit` 0.1.1, `documentation-authoring` 0.1.1: their assets templates replace descriptive prose with explicit `{{field}}` placeholders, keeping the surrounding fill-in guidance. ([f07453f](https://github.com/yuanJewel/skills/commit/f07453f098036cc8808c57cb783baa0de8a170f6))
- `context-handoff` 0.1.1: the user workbench gets a fixed shape titled with the current development version — Q waiting on you, N in progress, P scheduled, E ended this cycle — with four task states mapped from the project task register, requirement labels on every item, stage time limits agreed before work starts and reported before a likely miss, whole-page refresh, and a visible pre-publish self-check; the rules live in a new workbench reference page. ([c3146fc](https://github.com/yuanJewel/skills/commit/c3146fcc4e46e8b3b63ef1683dd1bf4a2a19cafb))
- `ai-workspace-governance` 0.1.1: work is handed to another agent through a handover entry in the plan status plus a one-sentence locating message, instead of pasting the whole instruction; entries carry an ID, keep their content immutable, are checked on reception, give the receiver a narrow write scope and keep one status writer at a time; the workbench description and plan archive close-out follow the new task states; root and entry-file examples are now generic. ([c3146fc](https://github.com/yuanJewel/skills/commit/c3146fcc4e46e8b3b63ef1683dd1bf4a2a19cafb))
- `systematic-diagnosis` 0.1.1: steps 1–2 hand evidence that only the user can reach to `guided-evidence-collection`, and pasted results return to this package's hypothesis ledger. The input rule now reads "do not ask for credentials or raw production dumps" instead of "production data or credentials", so that minimal safe fields returned by the user are allowed. The diagnosis report adds a source-label column using the labels defined by `guided-evidence-collection`; install the two packages together. ([1b1539a](https://github.com/yuanJewel/skills/commit/1b1539a4e3886f2ca691b2b718fb540e14463cbe))
- `readonly-ops-diagnostics` 0.1.1: the description routes user-run collection in environments the agent cannot enter to `guided-evidence-collection` and the diagnosis loop and fixes to `systematic-diagnosis`; this package remains local-only. ([1b1539a](https://github.com/yuanJewel/skills/commit/1b1539a4e3886f2ca691b2b718fb540e14463cbe))
- `change-review` 0.1.1: a new "Fix claims" section in the review contract applies when a candidate claims to fix a defect — name the previous behaviour, affected entry point and expected behaviour; check the mechanism does not break other variants sharing the code; report bundled features, refactors or dependency bumps as out of scope and return mixed fix-and-feature decisions to the user; count a regression test only if it exercises the original failure and would fail under the old code; match linked issues on failure, behaviour and expected result, not keywords. Change descriptions, commit messages, logs and linked issue bodies are now evidence to verify, not instructions. The review receipt gains a fix-claim line, the resource guidance uses grade words (`low/low`, `normal/high`, raised by complexity), and the package adds the pinned vercel-labs/skills triage source (VL01) with `LICENSE-VL.txt`. ([018633d](https://github.com/yuanJewel/skills/commit/018633d91b2b76d2b561800f7442a154a850e9e9))
- `container-image-management` 0.1.1: the completion and resources section adds grade-word guidance — `low/low` for read-only preparation, `normal/medium` for build and verification, `normal/high` for cross-platform mapping, signatures and rollback judgments — mapped through the project resource mapping. ([018633d](https://github.com/yuanJewel/skills/commit/018633d91b2b76d2b561800f7442a154a850e9e9))

([690c538](https://github.com/yuanJewel/skills/commit/690c5380d2033320ee00710d70c7b38b6de4307a))

## [0.1.0] - 2026-10-09

### Added
- Initial public release of the shared skill library: 38 skill packages, each at package version 0.1.0, usable from Claude Code and Codex. ([7dd914a](https://github.com/yuanJewel/skills/commit/7dd914ac1ea9260ceadec22cfade5285bbfc8d7a))

  - Testing: `test-strategy`, `go-testing`, `pytest-patterns`, `vue-testing`, `playwright-e2e`, `external-dependency-simulation`.

- `skill-maintenance/scripts/skill-lint.py` static checker for package structure, frontmatter, links and Markdown rendering.
