# Experiment protocol card

Fill this into the project's existing experiment plan for a substantial new comparison. A replay may cite the
original protocol and record only the changed fields. Replace every field with evidence or an explicit
unresolved item before execution; this is an authoring aid, not a runtime instruction.

| Decision                                     | Filled value and source                                               |
| -------------------------------------------- | --------------------------------------------------------------------- |
| Research claim and competing explanation     | {{claim; alternative}}                                                |
| Mechanism prediction and discriminating test  | {{predicted signal; controlled test; contrary result}}                |
| Practical benefit and its separate evidence   | {{outcome claim; matched outcome comparison}}                         |
| Outcome and acceptance criterion             | {{metric, direction, and observable threshold or decision rule}}      |
| Comparison rows and sole intended difference | {{baseline, strong alternative, full method, controlled removals}}    |
| Adopted framework and baseline source        | {{paper, repository, version, original script and command}}           |
| Artifact or model and code version           | {{identity and source}}                                               |
| Data, input selection, sample count          | {{split, selection rule, count and source}}                           |
| Intervention and evaluation protocol         | {{procedure, budget, duration, randomization, precision if relevant}} |

| Observation boundary                         | {{unit, start and stop if timed; included and excluded work}}         |
| Repetitions and aggregation                  | {{counts, pairing, weighting, and summary rule}}                      |
